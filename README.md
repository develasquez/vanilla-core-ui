**Vanilla-Core Architect** is an **AI Agent Skill** designed to guide coding assistants (Google Antigravity, Claude, Cursor, Gemini) in architecting, building, and maintaining robust, zero-framework, high-performance frontend applications using the strict **Vanilla-Core Architecture**.

---

## 🌟 What is Vanilla-Core Architecture?

Vanilla-Core is a hardened frontend pattern that enforces a clean, predictable, single-source-of-truth dynamic architecture without framework bloat or virtual DOM overhead.

### The 7 Core Principles (The Dogma)

Every application generated by this skill strictly adheres to seven non-negotiable principles:

1. **Single Source of Truth (SSoT) 🧠:** The application's entire dynamic state is contained within a central `store.js` module. The UI is always a direct reflection of this state.
2. **Read-Only State for Components 🔒:** Modules outside `store.js` MUST NEVER mutate the state object directly. State modification is handled exclusively via `setState()`.
3. **Unidirectional Data Flow (Pub/Sub) 📢:** User interactions in components publish state changes via `setState()`. The store notifies subscribed UI renderers, decoupling components completely from one another.
4. **Strict Separation of Concerns (SoC) 🏗️:** Code is rigorously organized by function into modular component folders (`components/header/`, `components/sidebar/`, etc.) containing the trio `component.html`, `component.css`, and `component.js`.
5. **Utility-First CSS & Layout Stability 🎨:** TailwindCSS utilities style elements directly. Collapsible panels animate `width` / `flex-basis` combined with `flex-shrink: 0` and `overflow: hidden` to prevent ghost layout shifts.
6. **Surgical Rendering & Anti-Thrashing (Focus Guard) 🛡️:** Renderers use DOM diffing and Focus Guards (`document.activeElement !== input`) so active user typing is never interrupted or wiped by re-renders.
7. **Geometric Consistency 📐:** Diagram/Canvas applications export all drawing (SVG curves) and hit-testing (click detection) math from a shared `utils/geometry.js` module.

## 🚀 Quick Start & Installation

You can install this skill into your local workspace or globally across your machine using `npx`:

### 1. Install in Current Workspace (Recommended)
Run inside your project directory:

```bash
npx vanilla-core-ui
```

This copies the skill to `.agents/skills/vanilla-core-architect/` where AI agents automatically discover and activate it.

### 2. Install Globally
Install across all projects on your system:

```bash
npx vanilla-core-ui --global
```

This copies the skill to `~/.gemini/config/skills/vanilla-core-architect/`.

## 📂 Project Directory Structure

Projects built with this skill follow a standardized, clean directory layout:

```text
my-vanilla-project/
├── components/                  # Self-contained UI components
│   ├── header/
│   │   ├── header.html          # Component markup
│   │   ├── header.css           # Component styles
│   │   └── header.js            # Component logic & event bindings
│   └── sidebar/
│       ├── sidebar.html
│       ├── sidebar.css
│       └── sidebar.js
├── ui/                          # Domain-specific UI renderers
│   ├── header-renderer.js
│   └── main-renderer.js
├── services/                    # API clients, storage, authentication
├── utils/                       # Pure helper functions
│   └── geometry.js              # Shared math for canvas/SVG drawing & hit testing
├── dom-elements.js              # Central mapping of global DOM containers
├── index.html                   # App Shell
├── load.js                      # Startup & component loader script
├── main.js                      # App orchestrator & Pub/Sub wire-up
├── server.js                    # Zero-dependency Node HTTP dev server
├── store.js                     # Central SSoT state & Pub/Sub engine
├── style.css                    # Global styles & Tailwind entry
├── changelog.md                 # Prepend-only change history
└── package.json
```

## 🤖 How AI Agents Use This Skill

When your AI pair programmer (Antigravity, Claude, Cursor, etc.) receives a request to create or update a Vanilla-Core web app, it activates `vanilla-core-architect` and follows these execution rules:

1. **BASH SCRIPT ONLY**: Outputs a single runnable Bash script using `cat << 'EOF'` to generate or overwrite files.
2. **COMPLETE CODE**: Overwrites files with FULL, complete code (never uses `// ... rest of code` ellipses).
3. **CHANGELOG PREPEND**: Prepends the change entry to `changelog.md`.
4. **GIT COMMIT MESSAGE**: Appends a standardized git commit message in English at the end of every response.
